**Описание**  
Разрабатываемое приложение представляет собой мобильную читалку для операционной системы Android, реализованную на языке Java в среде Android Studio.  
Приложение позволяет пользователю просматривать и читать файлы форматов EPUB и FB2, которые хранятся локально на устройстве.  
Для каждого пользователя создаётся индивидуальный профиль, данные которого (настройки, история, закладки) синхронизируются с сервером.  
Дополнительно реализован парсер веб-сайта ranobe.me для поиска и скачивания книг из сети с поддержкой поиска по названию и фильтрации по языкам.
________________________________________
**Основные функции приложения**  
— регистрация и авторизация пользователя;  
— хранение пользовательских данных на сервере;  
— парсинг веб-сайта ranobe.me с помощью библиотеки Jsoup;  
— поиск книг по названию с поддержкой русского языка;  
— фильтрация книг по языкам (английский, китайский, корейский, русский, японский);  
— отображение списка доступных книг в формате RecyclerView с вкладками (Все книги, Недавние, Избранное);  
— чтение локальных файлов EPUB и FB2;  
— сохранение закладок и истории чтения;  
— управление избранными книгами;  
— автоматическое извлечение обложек книг;  
— оптимизированная загрузка больших книг (постраничная загрузка);  
— возможность офлайн-доступа к ранее загруженным книгам.

**Используемые технологии и библиотеки**  
— Jsoup — парсинг HTML-контента с веб-сайта ranobe.me;  
— Собственный парсер EPUB (EpubParser) — чтение и парсинг файлов EPUB;  
— Собственный парсер FB2 (Fb2Parser) — чтение и парсинг файлов FB2;  
— WebView — отображение содержимого книг;  
— Room — локальная база данных для хранения книг, истории чтения и закладок;  
— Retrofit / OkHttp — взаимодействие с сервером (API для авторизации и синхронизации);  
— Glide — загрузка и кэширование обложек книг;  
— SharedPreferences — хранение пользовательских настроек;  
— RecyclerView и CardView — интерфейс списка книг;  
— Material Design Components — современный UI/UX дизайн.
